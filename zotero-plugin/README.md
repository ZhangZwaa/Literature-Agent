# Zotero Plugin V0.1

Minimal control surface for the local Literature Agent.

It expects the local service at:
`http://127.0.0.1:8765`

Menu location:
`Tools -> Literature Agent`

Commands:
- Agent Status
- Scan Now
- Process Selected Paper
- Re-summarize Selected Paper

This is source/development packaging. Zotero extension packaging details can change between Zotero releases, so test it against your installed Zotero version before relying on it as the only control path.
